    5. **Initialize Three.js.**
       - Constants: `PARTICLE_COUNT = 10000`, `PARTICLE_SIZE = 0.15`.
       - `THREE.Scene` with `FogExp2(0x000000, 0.02)` for depth.
       - `PerspectiveCamera(60, aspect, 0.1, 1000)` at `z = 50`.
       - `WebGLRenderer({ antialias: true, alpha: true })`, sized to viewport, `setPixelRatio(devicePixelRatio)`.
       - `OrbitControls` with `enableDamping = true`, `dampingFactor = 0.05`, `autoRotate = true`, `autoRotateSpeed = 0.5`.
       - One `THREE.BufferGeometry` with a `position` attribute (Float32Array of length `PARTICLE_COUNT * 3`) initialized to random values in `[-50, 50]`.
       - One `THREE.PointsMaterial` with `color: 0xff007f`, `size: PARTICLE_SIZE`, `map` loaded from `https://threejs.org/examples/textures/sprites/disc.png`, `transparent: true`, `opacity: 0.95`, `blending: THREE.AdditiveBlending`, `depthWrite: false`.

       - Handle window resize (update camera aspect + renderer size).

    6. **Implement the seven shape templates.** Each is a function `fillX(buffer)` that writes target xyz triples into a Float32Array of length `PARTICLE_COUNT * 3`. Use these formulas exactly:
       - **Sphere:** Fibonacci-like distribution: `phi = acos(-1 + 2i/N)`, `theta = sqrt(N·π)·phi`, radius `r = 10`, then standard spherical → Cartesian.
       - **Heart:** classic 2D heart curve `x = 16·sin³(t)`, `y = 13·cos(t) − 5·cos(2t) − 2·cos(3t) − cos(4t)` for `t ∈ [0, 2π)`, scaled by 0.5 and a random `s = sqrt(rand())` for interior fill, with `z = (rand − 0.5)·6·s` for thickness.
       - **Flower:** rose curve, `k = 4` petals: `r = 10·|cos(k·θ)| + 2`, `z = (rand − 0.5)·5·|cos(k·θ)|` (thicker at petal tips).
       - **Saturn:** 70% of points form a sphere body of radius 6 (Fibonacci distribution); the remaining 30% form a thin flat ring (radius 9–16, y-thickness 0.5) tilted 20° around the X axis.
       - **Buddha:** stacked solid spheres approximating a seated figure: head (center `(0, 6, 0)`, r=2.5, ~15% of points), torso (`(0, 2, 0)`, r=4.0, ~45%), two leg/base spheres at `(±3, −3, 1)`, r=2.8, ~20% each. Use `r = radius·∛(rand())` for uniform solid distribution.
       - **Fireworks:** uniform radial burst — random direction on the unit sphere (`theta = rand·2π`, `phi = acos(2·rand − 1)`), random length `len = rand·15`.
       - **MUHU text:** off-screen 2D canvas (200×100), draw black background, then `bold 60px Arial` white "MUHU" centered. Sample every 2nd pixel; where `red > 128`, push a 3D point with `x = (px − 100)·0.25`, `y = (50 − py)·0.25`, `z = 0`. Cache the result. When filling the buffer, loop indices over the cached point list (wrap with modulo + slight random offset for overflow particles). The label promises "High Five → Heart": when the user closes their fist while this template is active, particles should morph to the heart shape (precompute a separate `heartBuffer` once at startup for this).

    7. **Hand tracking via MediaPipe.**
       - Construct `new Hands({ locateFile: f => 'https://cdn.jsdelivr.net/npm/@mediapipe/hands/' + f })`.
       - `setOptions({ maxNumHands: 2, modelComplexity: 1, minDetectionConfidence: 0.5, minTrackingConfidence: 0.5 })`.
       - Use `new Camera(videoElement, { onFrame: () => hands.send({ image: videoElement }), width: 640, height: 480 })` and `.start()`.
       - On `.start()` success, set status to "Camera Active. Tracking Hands..." with `.active` class. On failure, set "Camera Error! Check permissions." with `.error` class — the app must keep running with idle/auto animation.
       - In `onResults`, if landmarks exist:
         - Use the first hand. Compute average Euclidean distance from wrist (landmark 0) to fingertips (8, 12, 16, 20).
         - Normalize: `handTension = clamp((avgDist − 0.15) · 3, 0, 1)`.
         - `handClosed = handTension < 0.2`. Set `handDetected = true`.
       - If no hand: `handDetected = false`, `handTension = 0.5`, `handClosed = false`.

    8. **Render loop (`requestAnimationFrame`).**
       - Maintain a `targetPositions` Float32Array. `setTemplate(type)` writes new targets into it (do NOT snap current positions — let the loop interpolate).
       - Each frame, lerp current positions toward `targetPositions` with `speed = 0.05 + handTension·0.02`.
       - Special case: if `currentTemplate === 'muhu' && handClosed`, lerp toward the precomputed `heartBuffer` instead.
       - Map hand tension to scale: `targetScale = 0.5 + handTension·1.5`, then lerp `particles.scale` toward it (factor 0.1). Open hand = expanded, fist = compressed.
       - When `!handDetected`, add gentle idle noise: `+= sin(time + i)·0.02` on x, `+= cos(time + i·0.5)·0.02` on y.
       - When `currentTemplate === 'fireworks'` and a hand IS detected, add per-frame jitter `(rand − 0.5)·0.2` on all three axes for a sparking effect.
       - Mark `geometry.attributes.position.needsUpdate = true`. Update `OrbitControls`. Render.

    9. **Wire the UI.**
       - Color picker `input` event → `materials.color.set(value)`.
       - Template buttons `click` → toggle `.active` class on the clicked button only, then call `setTemplate(btn.dataset.type)`.

    10. **Boot order.** `initThree()` → `initUI()` → `animate()` → `setTimeout(setupMediaPipe, 1000)` (slight defer so the UI paints before the camera permission prompt).

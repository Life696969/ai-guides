The prompt anatomy

Use this when quality matters. You do not need all six parts every time, but serious output needs structure.

Role

Who should the AI act as?

Example: Act as a social media strategist.

Task

What should it create?

Example: Create 10 reel hooks.

Context

What changes the answer?

Audience, goal, situation, background, references.

Input

What material should it use?

Paste the transcript, notes, topic, screenshot summary, data, or idea.

Format

What should done look like?

Table, checklist, script, JSON, email, plan, spec, or copy-paste version.

Constraints

What must it avoid?

Tone, length, style, things to include, things to avoid, success criteria.

Universal template

Act as [role].
Your task: [specific task].
Context: [audience, goal, situation, background].
Input: [paste the material or idea].
Output format: [table / bullets / script / checklist / JSON / plan].
Constraints: [tone, length, style, things to avoid].
Before final answer, check the output against: [success criteria].

Upgrade: Make reasonable assumptions, but list them before answering.

Weak prompt → useful prompt

Copy the pattern. Weak prompts ask for a topic. Strong prompts define audience, goal, format, constraints, and use case.

Creator

Weak: Give me reel ideas.

Strong: Give me 10 reel ideas for Indian students learning AI. Each idea must have a hook, 20-second script angle, caption value, and why someone would save it. Avoid generic productivity advice.

Student

Weak: Explain DBMS.

Strong: Teach me DBMS normalization for an exam. Explain in simple words, give 3 examples, create 10 active recall questions, then give common mistakes and a 2-day revision plan.

Founder

Weak: Make my app idea better.

Strong: I am building a turf booking app for Jaipur. Users need discovery, real-time slots, payments, and teams. Analyze the idea, list user flows, MVP screens, risks, and the first version I can test in 7 days.

Coding

Weak: Build a website.

Strong: Create a landing page spec for a free prompting guide. Include sections, copy, CTA, form fields, mobile layout, success states, and implementation steps for a coding agent.

Turn prompts into workflows

The real skill is not one perfect prompt. It is a repeatable process that turns inputs into assets.

Content

Idea → Asset

Idea → hooks → script → caption → pinned comment → thumbnail text → final post

Study

Topic → Revision

Topic → simple explanation → examples → active recall → test → weak areas → revision plan

Research

Question → Brief

Question → source list → summary → counterpoints → uncertainty → action checklist

Build

Idea → MVP Spec

Idea → user problem → feature list → screen map → product spec → code prompt → tests

Do not stop at ideas. Turn the answer into something usable: a doc, page, script, workflow, spec, or testable product.

Prompt troubleshooting matrix

When the output is bad, do not blame the model immediately. Fix the instruction first.

ProblemLikely causeFix
Generic answerNo audience, goal, or examples.Add audience, constraints, and 2 examples.
Too longNo length limit.Set word, line, or section limit.
Wrong toneNo style direction.Add tone, examples, and avoid list.
Misses detailsContext not separated.Use headings: Goal, Input, Rules, Output.
Makes things upNo source rules.Ask it to cite sources or say “not sure.”
Messy outputNo format specified.Request exact table, checklist, or template.
Does not improveNo feedback loop.Ask it to score and rewrite against criteria.
20-minute routine

Prompt upgrade sprint

0-3 min: write messy prompt. 3-7: add audience, context, constraints, format. 7-12: ask AI to critique prompt. 12-16: run improved prompt. 16-20: rewrite once and save.

Troubleshooting prompt

Diagnose before rewriting

The output below is not good enough. Diagnose why.
My original prompt: [paste]
AI output: [paste]
My goal: [goal]
Tell me what was missing from the prompt. Then rewrite the prompt and produce the improved output.
